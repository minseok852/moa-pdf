PDF.js 6에서 문서 해제 API가 변경되어 로딩 작업 객체를 직접 해제하도록 수정했습니다. 로딩 중 취소와 전체 캐시 정리 테스트를 추가했습니다. 빌드할 때 이전 버전의 생성된 PDF 보조 파일 디렉터리도 제거합니다.

실제 PDF.js 엔진의 로딩·텍스트 추출·해제는 `npm run test:pdf`로 검증합니다. 이는 브라우저 화면·CSP 검증과 별개입니다. 로컬 네트워크 제한 때문에 의존성 갱신과 새 설치 검증은 GitHub Actions에서 수행했습니다.
