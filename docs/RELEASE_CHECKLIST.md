## 공개 전에 남은 확인

- [ ] 네트워크가 가능한 환경 또는 GitHub Actions에서 `npm ci`로 새 설치
- [ ] `npm audit --audit-level=high` 성공 확인. 현재 실행 환경에서는 npm 레지스트리 DNS 조회가 실패해 보안 검사 결과를 얻지 못함

- [ ] 한국어 PDF와 특수 이미지 코덱 PDF 실파일 확인
- [ ] 모바일 조작, 저장/복구, 큰 문서 성능 확인

자동 검증만으로 실제 브라우저 화면이나 모든 입력 PDF의 정상 동작을 보장하지 않습니다. Vite의 큰 번들 경고는 남아 있으며, 빌드는 성공합니다. 첫 화면 용량과 큰 PDF 메모리 사용은 후속 성능 개선 대상입니다.
